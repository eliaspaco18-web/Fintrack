## Implemented and preserved

- One persistent bottom-right `Registrar` uses the shared anchored action menu. It exposes the eight existing `OperationType` identities in the approved order: expense, income, transfer, receivable issue/collection, payable issue/payment and asset purchase. Each URL uses the existing `new=transaction` and `type`/`module` query contract; no account, receivable or payable target ID is preselected. Only Cuentas, Presupuestos and Créditos add their existing contextual create deep link.
- The menu groups operations without adding a new financial operation. It is viewport-clamped, opens above the bottom trigger, supports Arrow/Home/End/Enter/Escape/Tab, retains trigger focus on pointer opening, dismisses on outside focus/scroll/route change and uses the approved 160/110ms anchored timing. The 52px desktop/tablet and 56px mobile control keeps the plus-to-close rotation, a single session intro and reduced-motion bypass. The menu itself can scroll on a short viewport without dismissing.
- The mobile 68px dock has three real destinations (`/dashboard`, `/transactions`, `/portfolio`) plus `Más`; `Registrar` owns a reserved right slot rather than covering a record. `Más` opens the shared V3 workbench with all existing gated navigation. The 52px mobile topbar shows the shared 27px FT12 mark and current section, without another hamburger. The desktop/tablet shell and mobile navigation use the same route IDs and environment gates.
- The former topbar `Nueva` menu and utility-filled FAB are removed from the visible shell to avoid duplicate generic creation and non-operational menu items. Theme remains in topbar/profile; the existing currency view toggle moves intact to profile. Profile and security links remain. Module-specific creation paths, including Plantillas, are not removed from their owning modules. The old `MobileDrawer` implementation is retained in source for a scoped code rollback but is no longer mounted.
- The FAB is moved outside the workspace transform so sidebar collapse does not move its viewport anchor. The existing modal background ownership makes it inert behind a V3 workbench; the menu itself closes on route and source scroll.
